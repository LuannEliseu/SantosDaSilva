## [1.0.0] - 2026-03-12

### Added
- Criada a estrutura inicial do site.
- Implementada a página de apresentação.
- Desenvolvida a seção **Sobre Mim**.
- Criadas as seções Formação, Portfólio e Contato.
- Implementada a identidade visual com predominância das cores preto e vermelho.
- Adicionada adaptação para dispositivos móveis utilizando CSS Media Queries.
- Implementadas interações e navegação por botões.
- Adicionada validação dos campos do formulário utilizando JavaScript.
- Implementado o envio dos dados do formulário diretamente para o WhatsApp.
- Documentado o código-fonte do projeto.

### Changed
- Renomeada a seção `Sobre` para `Sobre Mim`.
- Renomeada a seção `Projeto` para `Portfólio`.
- Ajustados os posicionamentos dos elementos utilizando `position: absolute`.
- Aprimorada a responsividade para dispositivos móveis.
- Melhoradas as interações dos botões e elementos da página.

### Fixed
- Corrigidos problemas de posicionamento dos elementos.
- Corrigidos bugs relacionados ao formulário.
- Corrigidas falhas nas interações dos botões.
- Realizados testes e ajustes finais para garantir o funcionamento do site.

## Estrutura do projeto

- `src/css/` — Arquivos responsáveis pela estilização e identidade visual.
- `src/images/` — Imagens utilizadas no site.
- `src/scripts/` — Scripts JavaScript e funcionalidades.
- `index.html` — Arquivo principal com a estrutura HTML.
